## струтура API

**архитектура:**
архитектура ссылки на API такова: `/api/v1/<функция>`:
 - `/` - корень, при обращении перенапровляет на главный сайт
 - `api` - основа показывающая обращения именно к API
 - `v1` - версия API (на будущее)
 - `<функция>` - функция коя будет вызвана из API; пример `ping` - проверка отклика, возвращяет `200`
 
**функции:**
- `ping` - проверка отклика, возвражяет `200`
- `new_user` - создание нового пользователя; метод: POST; данные: role, name, surname, email, password, classU
